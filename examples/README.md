# Examples

Examples are intended to show **how the workflow behaves**, not just what the files look like.

## Cross-platform V1

Path:

```text
cross-platform-v1/
```

Demonstrates:

```text
Iteration 01 — Feature Complete
→ Windows environment unavailable
→ Windows validation is deferred, not made a blocker
→ Runtime/Web/Installer/Update implementation continues
→ Human runs the integrated system
→ reconnect and upgrade problems become more important
→ iteration result records new reality
→ deferred ledger preserves Windows obligations
→ Iteration 02 promotes integration debt
→ Windows validation remains intentionally deferred
```

This example illustrates the two most important rules:

```text
Iteration Complete ≠ Release Ready
Remembered ≠ Scheduled Now
```

Future examples should focus on distinct project patterns rather than duplicating the same mechanics.
